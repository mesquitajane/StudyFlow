# StudyFlow

É um sistema de organização e controle de progresso estudantil.

## Sobre o projeto

O **StudyFlow** é uma aplicação desenvolvida para auxiliar na organização e no acompanhamento da rotina escolar de alunos, professores, responsáveis e equipe administrativa.  
O sistema centraliza informações acadêmicas como tarefas, notas, presença, relatórios de desempenho e relatórios comportamentais, oferecendo uma interface simples, intuitiva e acessível.


## Funcionalidades

- Cadastro e autenticação de usuários.
- Perfis distintos para aluno, professor, responsável e secretaria.
- Cadastro e gerenciamento de tarefas escolares.
- Lançamento e consulta de notas.
- Controle de presença.
- Acompanhamento de desempenho acadêmico.
- Emissão de relatórios acadêmicos.
- Emissão de relatórios comportamentais.
- Acesso de responsáveis às informações dos alunos.
- Painel administrativo para a secretaria.

## Requisitos mínimos

- Processador Intel Core i3 ou AMD Ryzen 3.
- 8 GB de memória RAM.
- SSD de 256 GB.
- Visual Studio 2022 instalado.
- .NET MAUI configurado no ambiente de desenvolvimento.
- SQLite para persistência dos dados.

## Como executar no Visual Studio 2022

1. Clone este repositório.
2. Abra a solução no **Visual Studio 2022**.
3. Aguarde o restore dos pacotes e dependências.
4. Verifique se o ambiente .NET MAUI está instalado corretamente.
5. Execute o projeto selecionando a plataforma desejada, como Windows ou Android.
6. Caso necessário, configure a conexão com o banco SQLite.

## Objetivo do projeto

O objetivo do sistema é facilitar a organização das informações acadêmicas, melhorar a comunicação entre os envolvidos no processo educacional e permitir o acompanhamento mais eficiente do progresso estudantil.

## Metodologia

O projeto foi desenvolvido com base na metodologia ágil Scrum, dividido em sprints para organizar as entregas e permitir evolução contínua do sistema.
